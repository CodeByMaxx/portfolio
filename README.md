## Projects

### Appointment Planner

A containerized appointment booking application for small businesses and service providers.

Customers can book available appointments, while operators can manage services, availability and appointments through a web dashboard.

**Stack**

* React
* TypeScript
* Vite
* Fastify
* Prisma
* PostgreSQL
* Docker
* AWS

**AWS**

* EC2
* IAM
* SES

**Topics**

* REST API
* Appointment scheduling
* Timezone handling
* Email notifications
* Docker deployment

**Status:** Working MVP deployed on AWS
